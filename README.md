# Game Engine Architecture

## Overview
This project illustrates a game engine architecture developed in C++ using Visual Studio 2022.

## Features
- **Memory Management**: Efficient memory allocation and deallocation using design patterns.
- **State Machines**: Implementation of state machines for game states and character management.
- **Physics Core**: Realistic physics simulation for game objects.
- **Audio Management**: Handling of audio sounds and sound effects.
- **Input Management**: Supports both computer and Xbox controller inputs.
- **Graphics Management**: Rendering engine for 2D graphics.

## Technologies Used
Technologies used in this project:
- **OpenGL**
- **GLM**
- **SDL**.

## Installation
Feel free to clone the repository by using the link at the code button or just by downloading the zip file
